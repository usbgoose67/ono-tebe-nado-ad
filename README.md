# Оно тебе надо

Учебный проект: адаптивная вёрстка главной страницы вымышленного аукциона вещей, в которые никто не верил. Страница сверстана по макету в Figma.

Репозиторий: https://github.com/usbgoose67/ono-tebe-nado-ad

## Что внутри

- Семантическая разметка: `header`, `main`, `section`, `article`, `address`, `nav`, `footer`
- Именование классов по методологии БЭМ
- Раскладка на flexbox и grid
- Подключение шрифта Raleway (woff2 и woff)
- Фоновые изображения и полупрозрачный оверлей
- Страница рассчитана на экраны ноутбуков, ширина макета 1100px

## Структура проекта

- `index.html` — главная страница.
- `styles/` — глобальные и локальные стили.
- `fonts/` — шрифты и их подключение.
- `images/` — изображения и иконки.

## Как открыть

Откройте файл `index.html` в браузере. Запускать сервер не нужно.
